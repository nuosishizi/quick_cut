快剪 QuickCut 2.7.2

Windows 版：
1. 安装 Node.js LTS（https://nodejs.org/）和 FFmpeg，并确保命令行能运行 node、ffmpeg、ffprobe。
2. 双击项目根目录的“启动快剪.bat”，或在 PowerShell 中运行“启动快剪.ps1”。
3. 程序会启动本地编辑器，并用 Microsoft Edge 应用窗口打开。快捷键用 Ctrl，不再使用 Command。
4. Windows 无独立显卡时，在字幕页保存 Groq API Key，文案匹配走 Groq 云端 Whisper，无需下载 600MB 本地模型。Mac 仍可选用本地 Whisper Turbo。
5. 导出优先使用 NVIDIA / AMD / Intel 硬件编码，没有独显时回退到 libx264。

Apple Silicon 一次安装版：

2.7.2 说明：字幕描边统一为外描边；滤镜真实人像改为安装后仍可访问的应用内资源；美颜增加 GPU 失败时的实时回退；删除时间线片段会同步删除字幕列表词句并重算时间戳；导出磨皮链路改为快速保边降噪并补全进度解析。

2.6.1 说明：修正一次安装包对 Bun 运行组件使用旧尺寸和旧哈希校验的问题。安装器与 APP 启动器现在按包内实际组件校验，避免误报“运行组件准备失败”。

2.6.0 说明：正确字幕轨道始终使用完整正确文案，并通过局部重新锚定避免第一个错词造成后文整体错位；“8 to 10”等口头时间会显示为文案中的“8:00 PM to 10:00 PM”，and、but 等不改变原意的连接词默认忽略。待处理轨道中，绿色口语补充点击后插入正确字幕，红色错读或重复点击后仅剪除对应时间段并联动视频、音频和字幕向前吸附，待处理轨不参与导出。整轨降噪改为项目目录内原子写入，修复临时文件消失错误。拖拽、字幕宽度和时间线缩放不再在每一帧重建整条时间线。新增逐行放大字幕、30 款可调滤镜、LUT 导入与真实预览/导出，以及文字和图片各 10 款光效动画。

2.5.8 说明：待处理轨道分为两种真实操作：红色表示错读、重复或原意不符，点击只剪掉该时间段的视频和音频；绿色表示未改变原意的口语补充，点击接受该段声音。最终导出只使用一字不落的正确文案字幕，待处理轨道不导出。首尾改为快速人声边界识别，人声前后各保留 0.1 秒；内部长停顿仍保守剪辑。拖拽、字幕宽度和时间线缩放改为每帧合并更新，避免反复重建整条时间线。字幕始终最多两行，两侧控制点只调整换行宽度。

2.5.4 说明：修复导出、自动剪停顿和静帧共用的媒体探测兼容错误。普通素材改为关联原文件，增加当前工程缓存清理、素材丢失提示与重新关联；预览画布支持滚轮缩放和旋转选框。首次文案匹配会自动断点下载本地语音模型。软件自带并校验 Bun、FFmpeg、FFprobe、WebView 与语音识别运行组件，重装系统后使用本安装包即可重新安装。

2.5.0 说明：导出严格截止到所有可见成片素材的最晚结束位置，不再按时间线显示范围或差异诊断轨导出；时间线采用保留式渲染，滚动不再反复重建素材块。全部滑块加入减号/加号微调；字体、字间距、行间距统一放入右侧文字属性。导出默认使用 H.264 Apple 硬件加速、推荐码率、素材帧率和 Rec. 709 SDR，并带百分比进度条；硬件编码不可用时自动回退软件编码。

安装：
1. 适用于 M1、M2、M3、M4 及后续 Apple Silicon（ARM64）Mac。解压安装包后，右键“安装快剪.command”选择“打开”；后续直接打开“快剪.app”。
2. 第一次打开若被系统拦截，请在访达中右键应用，选择“打开”。

工程：首页可新建、打开和删除多个独立工程，编辑状态自动保存。首页支持工程备份和恢复，重装系统前请先导出备份。

推荐流程：
1. 新建工程后，把视频、音频、图片或字幕拖入素材区、预览窗口或时间线；也可通过导入按钮加入素材。单击素材库里的素材会直接加入时间线。快速停顿分析不加载 AI：0.3 秒以内不处理，长停顿只保留约 0.3 秒。
2. 在“字幕”页粘贴正确文案，并保存 Groq API Key；匹配时用 Groq 云端识别口播。字幕会使用正确文案逐词对应实际发音，额外的and、but等不改变意思的口语连接词会被忽略。
3. 正确文案会映射到可靠匹配的发音时间。错读、重复或意义完全不匹配的时段显示“⌫”；点击只删除这一小段视频和音频，后续视音频、字幕和其他关联素材同步吸附前移。文案漏读会显示“需补录”，不会伪造可删除的音频时段。
4. 视频、音频、图片、文字和字幕均可建立独立轨道；轨道可上下重排、显隐和删除。把片段纵向拖到其他轨道时会匹配同类型轨道或自动新建轨道。时间线支持框选、Shift/Command 多选、批量删除和片段两端修剪。
5. 人声降噪可试听播放头附近 8 秒，也可点击“应用整条音轨”生成时间线监听缓存；导出时始终按当前参数处理整条音频。音频面板支持整轨及片段音量、声像、淡入淡出、精准波形、均衡、压缩、齿音抑制、人声增强、响度标准化、限幅和声道复制。
6. 人像优化采用保边肤质平滑、色斑细纹弱化、质感恢复、肤色提亮、冷暖和自然红润，各项可独立调整。调色面板采用曝光、对比枢轴、Lift、Gamma、Gain、自然饱和度和中间调细节等独立参数。
7. 导出前可选择 MP4、MOV 或 MP3、分辨率、H.264/H.265、帧率和位元率。

快捷键：
空格：播放/暂停
Command+B：在播放头切割
Command+Z：撤销
Shift+Command+Z：重做
Command+S：立即执行一次自动保存
Command+A：选择时间线全部片段
Delete：删除选中片段
左/右方向键：前后一帧
Shift+左/右方向键：前后一秒
Q / W：删除播放头左侧 / 右侧
J / L：减慢 / 加快播放

重装与迁移：FFmpeg、降噪组件和运行环境随 APP 提供。Whisper Turbo 字幕模型首次使用时下载；重装系统后可重新下载。重置系统前请在首页导出工程备份，重装后使用“恢复备份”即可继续工程。

说明：工程采用非破坏式编辑，原视频不会被覆盖；软件仅处理主动导入的素材和自己的工程数据。未使用 Apple Developer ID 签名的安装包首次打开时，需要在访达中右键选择“打开”。
