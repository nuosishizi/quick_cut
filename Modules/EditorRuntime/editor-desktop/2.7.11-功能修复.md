# 快剪 QuickCut 2.7.11

有整句底的字幕不再走 AutoSubs 宏。

## 根因

AutoSubs 是逐词高亮引擎。它的 CLS 关键帧占用 Element 4：底会被拆成一块块，播放一会儿又被盖掉。硬黑边来自母版描边/阴影，Softness 被清成 0。

## 稳定做法

不要在 AutoSubs 母版上继续打补丁。有底时用普通 Text+：一层 Border Fill（整句 Level 0），关掉描边和硬阴影。词色只用 Element 1 的 CLS。

不必先手做模板。以后若要「底 + AutoSubs 动画」同时存在，再在达芬奇里另存一份带独立背景层的 `.setting`。
