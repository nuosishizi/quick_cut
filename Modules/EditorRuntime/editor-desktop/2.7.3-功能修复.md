# 快剪 QuickCut 2.7.3

新增「发送到达芬奇」：在快剪里对齐并调好字幕后，可直接铺到当前打开的达芬奇时间线。

## 怎么用

1. 快剪里做好字幕和样式。
2. 打开达芬奇，打开工程，时间线上放好同一条视频。
3. 第一次：达芬奇菜单点「工作区 → 脚本 → 快剪」（脚本由快剪自动装进达芬奇脚本目录）。
4. 回到快剪点「发送到达芬奇」。
5. 当前时间线会多一轨 Fusion Text+，带字体、字号、颜色、描边、阴影、位置和换行。一句一条，不加逐字动画。

点过一次脚本后会保持接收，之后只需在快剪里再点发送。

「导出达芬奇文件」仍在：导出一份达芬奇可直接「文件 → 导入时间线」打开的 fcpxml，包含主视频剪辑、字幕标题、叠加视频/图片/文字和音频轨。给没有装接收脚本、或要把工程交给别人的人用。

## 实现说明

接收脚本和发送协议都是快剪自己写的，只调用 Blackmagic 公开的 Resolve / Fusion API。字幕以 Text+ 片段写入单独的「快剪字幕」轨，不写到 V1，也不导入 caption-bin.drb。一句字幕对应一条 Text+，只写入基础样式（字体、字号、颜色、描边、阴影、位置、对齐）。
