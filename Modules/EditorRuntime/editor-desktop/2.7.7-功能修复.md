# 快剪 QuickCut 2.7.7

按 AutoSubs 宏技术做「快剪字幕」样式通道，不引入 MMS，不改预览/对齐/剪辑。

## 计划

1. 对外母版名改为「快剪字幕」。本机无法在没打开达芬奇时另导出 .drb，因此仍导入现有 caption-bin，导入后改名。
2. 整句底只写 Text+ Element 5。`BubbleEnabled` 只在当前词高亮为 Bubble（word-pill 等）时打开。
3. `presetSettings` 带 `AnimationLevel=0`、`AnimationLength=0`，整句全开。
4. 旧媒体池里的 AutoSubs Caption 仍能识别，并改名为快剪字幕。

## 验证

- `templateName === 快剪字幕`
- 开背景时 `BubbleEnabled === 0`（填色高亮）
- `word-pill` 时 `BubbleEnabled === 1`，整句底仍在 style 里
- 脚本含 `adopt_quickcut_template_name` 与 Element 5
