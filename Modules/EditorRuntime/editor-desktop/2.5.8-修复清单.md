# 快剪 QuickCut 2.5.8

- 待处理字幕不再使用遮挡文字的删除图标，直接显示错读、重复或多读内容；点击字幕本身仍只删除该时间段的视频和音频并同步吸附。
- 时间线滑块、加减按钮和组合键缩放统一以当前播放头为锚点，不再从时间线开头缩放。
- 断句优先遵守句号、问号和感叹号，结合实际停顿，并继续保持圣经章节为完整语义单元。
- 禁止把句末最后一个单词孤立到下一段，也不会把句号并入下一句话；字幕组最多十词、画面最多两行。
- 预览框四角保持整体等比例缩放，左右控制点仅调整文字框宽度和换行，字号不变。
- 导出的 ASS 字幕使用同一文字框宽度和智能换行边距，预览与成片保持一致。
- 保留 2.5.6 的时间刻度修正、完整异步识别结果、局部重新锚定和后续字幕恢复机制。
