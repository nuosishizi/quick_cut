# 快剪 QuickCut 2.7.34

本版相对 2.7.33：快剪预览和导出走同一套 Canvas 字幕，达芬奇发送仍走 AutoSubs。

- 预览字幕改为 Canvas 绘制，导出用同一套 `paintCaptionToContext` 出 PNG 叠加，字号、描边、底框不再各画各的。
- 发送到达芬奇仍是文字 + WordTiming + AutoSubs 5 步，不会改成发图片。
- GPU 导出跳过 CUDA 解码，只保留 GPU 编码；编码器 15 秒无进度则回退 CPU，避免停在「正在启动编码器」。
- 字幕换行与底框按实际绘制宽度收紧，2 行模式不再被估宽撑成 3 行或过宽胶囊。
