# 快剪 QuickCut 2.5.5

- 修复 Retina Mac 把窗口尺寸按物理像素减半的问题：窗口改用 macOS 逻辑尺寸，默认 1280×720、最小 960×540并居中，首页和编辑器首次打开即可完整呈现。
- 语音识别改为 45 秒独立窗口并重置上下文，单个错读或模型误识别不会影响后续整段音频；相邻窗口重叠词自动去重。
- 文案对齐改为单向局部重新锚定。每次不匹配后查找最近的可靠 2–6 词锚点，只处理锚点之间的局部错误，不再从第一处错误一直错到结尾。
- 额外 and、but 等不改变意思的口语连接词继续忽略；错读、重复、多读和完全不匹配保留精确删除标记；漏读只显示需补录。
- 字幕严格使用正确文案的大小写、标点及圣经章节格式；章节范围不拆错，标点不出现在下一条开头。
- 字幕不会跨过待删除错误区合并，单词较少的字幕也不会越过错误时间段强行拼接。
- 新增长文多错误、重复经文、错误后重锚、识别窗口去重及字幕不跨错误区等回归测试。
