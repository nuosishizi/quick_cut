# 快剪 QuickCut 2.4.6

- 安装包增加“一次安装”程序：自动备份旧版、清除 macOS 下载隔离、修复执行权限并打开软件。
- APP 启动时把 Bun、FFmpeg、FFprobe、WebView 原生模块复制到独立的 2.4.6 运行目录，避免 App Translocation 与 `EBADMACHO`。
- 启动失败时写入 `~/Library/Application Support/QuickCut/startup-error.log` 并显示错误。
- 不删除用户工程，不改动原始视频和工程数据库。
- 保留 2.4.4 与 2.4.5 的全部编辑器功能及工程数据格式。
