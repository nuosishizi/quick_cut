# 快剪 QuickCut 2.4.3 修复清单

基线：用户重新上传的 `QuickCut-2.4.2-Apple-Silicon.tar.xz`，本版直接从其中完整的 2.4.2 应用源码继续修复。

- [x] 固定“文件、素材、字幕、样式、字体”顶部页签高度与最小宽度，面板缩放时保持一行且不再被挤压隐藏。
- [x] 删除旧主视频且没有可提升的叠加视频时，清除旧视频的缩放、位置、速度、调色、美颜、降噪和主音频参数；下一条主视频按原始默认参数进入。
- [x] 主视频支持连续横向拖动；未命中吸附点时不再强制按 0.05 秒跳格。
- [x] 主视频横向位移同步到播放定位、主音频和真实导出，前方空隙导出为黑场而不是仅移动界面。
- [x] 主视频拖动时只更新现有片段几何，不再每个鼠标事件重建整条时间线。
- [x] 字幕样式面板保持深灰背景；黑色或过暗的预览文字、描边会使用高对比预览色，但不会改变实际套用的字幕样式。
- [x] 首页工程卡片改为 9:16 封面；返回首页时按当前主视频画面、画布裁切、缩放和位置生成新的竖版封面。
- [x] 应用窗口以 1920×1080 参数创建并自动最大化，在不同尺寸的 Apple Silicon Mac 显示器上完整落入可用屏幕区域。
- [x] 自动保存改为复用正在执行的保存任务，返回首页前会等待封面与工程状态都写入完成。
- [x] 版本更新为 2.4.3（build 43），保留蓝底白色剪刀图标。

验证：UI 脚本语法、菜单布局、素材参数重置、时间线拖动持久化、字幕预览对比度、窗口启动参数、9:16 封面真实生成和带前置空隙的视频/音频真实导出共 8 项自动回归全部通过。
