# 快剪 QuickCut 2.7.43

## 修复与优化清单

### 1. 降噪音轨在预览与导出之间的路由修复
- **整轨降噪母带直通**：导出时自动复用已生成的高清降噪缓存音轨（`state.denoisedAudio`），无需重复重新运行重型降噪算法；
- **动态主音频输入索引**：解决以往 FFmpeg 音频滤镜图写死 `[0:a]` 的问题，支持动态 `mainAudioInputIndex`，精准将预降噪音轨映射为 `[1:a]`，并顺延画中画、贴纸与字幕等其它输入索引；
- **杜绝二次降噪**：使用预降噪音轨时自动将导出阶段降噪强度置零，跳过冗余滤镜，保留全局 EQ、压限与音量等调音效果，大幅提升导出速度并保证音质纯净；
- **MP3 导出同步适配**：支持 MP3 格式的降噪母带直通与背景音乐混音。

### 2. 导出异常日志清洗与 UI 优化
- **分离进度流与错误流**：FFmpeg `-progress` 规范至 `stdout`，`stderr` 独立捕获真实报错信息；
- **智能错误信息清洗**：剔除冗长机器代码与配置日志，精准提炼关键错误；
- **UI 弹窗容器自适应**：导出状态弹窗增加最大高度与滚动控制，杜绝文本撑破屏幕。
