# 快剪 QuickCut 2.5.3

- 无修改视频：跟随原素材编码并直接复制音视频码流，不重新压缩。
- 有剪辑或效果：Apple VideoToolbox 硬件编码、自适应码率、高质量 Lanczos 缩放。
- 导出窗口显示准确成片时长、导出模式与实时进度，导出截止于最后一段可见素材。
- 字幕识别启用 Whisper large-v3-turbo 的 DTW 词时间戳、束搜索和局部重新锚定，首个错读不会让后文全部失配。
- 动画预览使用 requestAnimationFrame，修复动画时长操作触发脚本错误。
- 主视频分片可独立缩放、移动、旋转、不透明度和混合模式；图片与叠加视频具有相同属性。
- 每条轨道增加锁定按钮，锁定后不能在时间线或预览窗口误操作。
- 默认窗口按屏幕可完整呈现并保持可自由缩放。
