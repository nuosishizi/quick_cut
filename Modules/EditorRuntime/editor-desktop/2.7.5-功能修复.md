# 快剪 QuickCut 2.7.5

发送到达芬奇时，整句字幕背景不再丢失。

## 原因

AutoSubs Caption 的 Text+ 通道是 `1=填充`、`2=描边`、`3=阴影`、`4=当前词高亮气泡`。`ApplyHighlight` 会在高亮不是 Bubble 时强制关掉 Element 4。快剪预览里的整句底如果写到 Element 4 或指望 `BubbleEnabled`，到达芬奇后会被清掉。

## 修复

AutoSubs 5 步（裁剪 → 写文本 → WordTiming → SetInputValues → ApplyWordTiming）完成之后，再对 `Template` 的 **Element 5** 写入整句/整行圆角底。不改描边、阴影、逐词高亮。

下一次在快剪点「发送到达芬奇」会自动覆盖达芬奇里的 `快剪.lua`。请重新发送一遍字幕查看背景。
