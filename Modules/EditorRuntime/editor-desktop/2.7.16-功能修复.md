# 快剪 QuickCut 2.7.16

金底和字已经有了，当前词还是不变色。

## 根因

逐词高亮写到了错误的 Fusion 节点上。AutoSubs 用的是 `StyledTextCLS`，关键帧要 `SetKeyFrames(..., true)`，并且每一帧要写全句每个词的填色（当前词高亮，其余词保持原色）。上一版 `AddTool("CharacterLevelStyling")` 本身就不存在，关键帧等于没写上。

## 修法

按 AutoSubs 同一条链：给 Text+ 的 StyledText 加 Character Level Styling（`StyledTextCLS`），再给它的 CharacterLevelStyling 口加 BezierSpline，用全词数组写填充色关键帧。
