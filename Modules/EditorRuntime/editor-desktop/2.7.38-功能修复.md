# 快剪 QuickCut 2.7.38

本版相对 2.7.36：

1. **体检审校卡片双行明细对照与高亮诊断**：
   - 经文出入、读法差异、卡壳重读、缺读待补、气口等全面支持「🎙️ 实际口播」与「📄 文案原文」双行对照。
   - 自动生成逐字差分高亮与顶部智能诊断说明（例如明确标出经文用词差异、卡壳废话建议切除、文案漏读提示等）。
2. **体检审校面板头部绝对固定置顶**：
   - 修复 CSS 规则作用域，将「全局体检与审校标题、一键体检、气口阈值滑块、经文保护开关、分类筛选 Tabs、全选/反选/切勾选气口批量操作栏」统一牢固置顶。
   - 下方卡片列表独立平滑滚动，浏览 100+ 条目时操作按钮永远可见。
3. **体检审校数据完整持久化存档**：
   - 上次体检审校报告、气口勾选状态、已忽略标记全部纳入工程存档（`project.json`），关闭软件或切换工程后重新打开 100% 自动无缝恢复，无需重复扫描。
4. **播放控制条倍速播放调整**：
   - 播放控制条（循环播放旁）新增快捷倍速药丸按钮与下拉菜单，支持 `0.5×`、`0.75×`、`1.0×`、`1.25×`、`1.5×`、`1.75×`、`2.0×`、`2.5×`、`3.0×` 快速变速试听。
   - 内置自动变调补偿（`preservesPitch`），倍速预览时人声不尖叫、不变调、听感清晰自然。
   - 支持快捷键：`Shift + ]`（或 `Shift + .`）逐级加速，`Shift + [`（或 `Shift + ,`）逐级减速，`Shift + R` 一键恢复 1.0× 原速。
5. **图片贴纸/徽章叠加渲染与预览 100% 像素级对齐修复**：
   - 彻底修复图片贴纸（如 PNG 标题框、水印、表情包等）在导出时被错误强行按视频画布宽度拉伸撑满全屏、导致画面中间覆盖人脸的严重 Bug。
   - 统一前端预览标尺与 FFmpeg 渲染底层：保持贴纸原始自然像素宽高比例，按 `scale` 缩放因数与画布像素基准进行绝对精确的居中偏移映射，实现所见即所得。
6. **达芬奇级时间线非破坏性修剪与双向全轨波纹恢复（Non-destructive Ripple Recovery）**：
   - **向外拉伸恢复素材**：拖动片段左/右边缘向外拉时，自动从底层 `state.removals` 中逆向收缩/消除被切除的区间，释放原视频真实帧，最远可恢复至源视频 0.0s 起点或源视频末尾！
   - **全轨道双向波纹联动**：向外拉长/恢复片段时，下游所有轨道（主音视频、副视频画中画、音频资产、贴纸、文字、台词字幕）自动向后平移波纹让出空间；向内修剪缩短时，下游全轨道自动向前波纹吸附闭合，紧凑无缝。
   - **切口滚筒与滑移编辑**：支持相邻接缝 Rolling Edit 双向微调切点与 Slip Edit 滑移素材内部范围。
