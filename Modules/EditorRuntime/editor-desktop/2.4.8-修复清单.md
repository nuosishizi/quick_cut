# 快剪 QuickCut 2.4.8

- 替换被截断的 FFmpeg，并校验 Bun、FFmpeg、FFprobe、WebView 和 Whisper 五个原生组件的完整性。
- 使用独立 `runtime-2.4.8` 目录，不再读取 2.4.7 的损坏缓存。
- 默认以居中、非全屏的 1200×675 逻辑窗口打开，完整展示首页和编辑器，仍可自由缩放。
- 进入工程时先显示界面，后启动媒体检查；不再为所有副轨素材同时启动 FFmpeg 分析。
- 面板和窗口拖拽时仅更新几何位置，松开后再重绘完整预览，减少卡顿。
- 主音轨恢复密集、细线的青绿色音波，加强低音量起伏的可见性。
- 口播字幕轨以深绿色显示匹配内容、黄色显示相近内容、红色显示读错/重复/多读内容，字体统一为白色。
- 正确文案轨优先显示精确的正确词句，“替换”只修改对应错词，不再覆盖整段字幕。
- 多读或重复片段显示“剪掉”，点击后同步紧缩视频、音频、字幕和其他轨道。
