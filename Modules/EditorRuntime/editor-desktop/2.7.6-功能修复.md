# 快剪 QuickCut 2.7.6

2 行字幕不再把剩下的词硬塞进最后一行导致出框。截图句 `Listen carefully— because the third one is the only sin` 在常见字幕框宽度下，每个词都留在框内。

## 原因

预览里每个词有 `margin-right: 0.24em`，换行却只按 `0.28em` 字距估算。2 行模式填满第一行后，余下全部堆到第二行，哪怕已经比框宽。`sin` 被裁在右边。

## 修复

- 行宽按真实预览计算：空格 + 词右边距 + 末词边距。
- 一行装不下就换行，绝不再往最后一行硬塞。
- 1 行 / 2 行 / 3 行 / 多行都先按行数切卡片，再保证每一行不超出框。
- 打开旧工程会按当前框宽重新切句。
