# 快剪 QuickCut 2.7.32

本版相对 2.7.27：听写、纠正、时间线删除、气口和浏览器缩放。

- 本地 Whisper 选项、模型选择、全量语种和下拉内搜索。
- AI 纠正增加 Antigravity CLI（agy）：检测、安装、登录；走本机 Gemini 套餐，不用 API Key。听写仍用 Groq / Deepgram / 本地 Whisper。
- 纠正对比日志写到本机 `QuickCut/logs`，控制台打印每条判定。
- 框选时间线按达芬奇切开范围内片段，只删选中的音视频，后面没选中的音频保留。
- 气口设置接回 2.7.5 的秒级停顿、呼吸留白和底噪灵敏度，达芬奇 dB/帧放在精细项。
- Ctrl+滚轮 / 捏合只缩放时间线或预览，不再缩放整个浏览器页面。
