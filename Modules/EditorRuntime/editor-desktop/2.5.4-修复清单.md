# 快剪 QuickCut 2.5.4

- 兼容安装包内置 FFprobe：导出、自动剪停顿、静帧和素材分析统一使用兼容查询。
- Finder 素材采用原文件关联；缺失时停止预览并提供重新关联，不再用缓存冒充原素材。
- 当前工程增加缓存清理；工程首页封面在主素材缺失时同步留空。
- 预览画布支持鼠标滚轮 25%–400% 缩放；旋转对象的选择框和控制点同步旋转。
- 系统网页右键菜单被应用内菜单替代；素材、时间线和预览区提供真实操作。
- 工具栏加号改为直接添加文字；空白时间线右键新增对应轨道。
- 默认窗口改为居中 1440×810，保持 16:9 且完整展示编辑布局。
- 延迟系统字体扫描，降低首次进入工程时的卡顿。
- Whisper Turbo 首次匹配自动下载，支持断点续传与文件完整性检查。
- Bun、FFmpeg、FFprobe、WebView 和本地语音运行组件随安装包携带并在安装及启动时校验、自修复运行缓存。
