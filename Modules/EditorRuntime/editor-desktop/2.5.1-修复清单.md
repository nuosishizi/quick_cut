# 快剪 QuickCut 2.5.1

- 长文对齐改为锚点间的局部词组对齐，一处多读不再导致后续整段变红。
- 口播字幕保留全部识别文字：绿色匹配、黄色相近、红色错读/多读/重复。
- 正确文案轨只显示不一致的正确词组；匹配内容不重复显示。
- 点击正确词组，只替换同时段的错误字幕；不改整条字幕。
- 点击口播轨红色词组，只剪掉该词组的视频、音频和字幕时间，后续素材自动前移。
- 漏读文案只在正确文案轨显示“需补录”，不伪造可剪时间。
- 标点不会单独落到下一句开头；“Matthew 24:36”、“2 Timothy 3:1”等经文引用不拆分。
- 右侧新增动画库：30 个文字动画、30 个图片动画，入场和出场独立。
- 动画卡片鼠标移入即预览；套用后保存到当前素材，并参与导出。
- 文字属性增加词间距、水平/垂直对齐、整体/逐行背景、背景宽高与偏移。
- 阴影增加颜色、不透明度、模糊、距离和角度。
- 每个滑块均有减号、加号和单项重置按钮。
