# 快剪 QuickCut 2.7.23

时间线按达芬奇联动选择来：关联、剪辑、删除。图片拖入默认 100%。

## 关联

联动按钮不再把时间上重叠的字幕、图片、文字、待处理条一起绑走。只绑：

- 主视频 + 主音频（联动开启时）
- 叠加视频和它抽出的音频（同一 `linkGroupId`）

点选、框选、拖动、切割、删除都走这组。关闭联动后，各片段独立。

## 删除 / 剪辑

- Delete：只拿掉所选（含成组音画），留下空隙
- Shift+Delete /「删除并前移」：主时间线仍整段波纹；叠加轨道只在本轨把后面的片段前移
- 后面的合法字幕只平移，不会被同轨前移吞掉

## 图片

拖入和静帧默认 `scale: 1`。导出兜底也是 100%，不再按 35%。
