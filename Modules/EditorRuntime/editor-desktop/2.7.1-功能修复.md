# 快剪 QuickCut 2.7.1

- 正确字幕使用粘贴文案原词并在每次局部错误后重新锚定，避免第一处错误导致后半段全部错位。
- 待处理轨道：红色错读/重复可精确删除对应视频与音频；绿色口语补充可插入当前字幕时间段。
- 左侧字幕页显示断行列表，可逐段修改，也可保持全部时间戳按当前断行一键替换正确文案。
- 视频、图片、文字与字幕拖到画面中线时吸附并临时显示竖向参考线。
- 逐行跳动从 20% 调整为 30%；字幕朗读高亮颜色与开关可编辑。
- 30 款滤镜统一换用真实手机人像样片，可直观对比肤色、阴影和色调差异。
- 美颜预览改为 GPU 保边平滑、斑点弱化、细节恢复、美白与肤色调整组合，数值改变会立即反映到画面。
- 预览窗口拖拽只更新当前选中素材的 GPU 合成层，拖动期间不再重建时间线、字幕词节点和其它图层。
- 保留已验证的完整 Apple Silicon 运行组件、自动剪停顿、降噪、静帧和硬件导出链路。
