# 快剪 QuickCut 2.7.10

达芬奇终于按母版里**真实存在的层**画整句金底。

## 第一性原理

AutoSubs Caption 的 Text+ 只保存了 Element 1–4。对 Enabled5 / Type5 的写入不会生成新的 Shading 层，所以底永远出不来。字色和高亮已经对（黑字、白词），底必须占用母版里已有的 Element 4。

实现路径只有这些：

1. Text+ Border Fill（官方底）——只能写在已存在的 Element 上
2. AutoSubs Bubble（词级，不能当整句胶囊）
3. 普通 Text+ `apply_style`（无 AutoSubs 词高亮）
4. 另做 Fusion 矩形+Merge（要改母版节点图）

本次用 1：在 ApplyHighlight 关掉 Element 4 之后，把它收成 `Type=1 Border Fill` + `Level=0 Text`。

## 验证

发送后应是：金色整句胶囊 + 黑字 + 当前词白高亮。必须重新发送。
