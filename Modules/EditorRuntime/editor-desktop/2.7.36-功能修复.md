# 快剪 QuickCut 2.7.36

本版相对 2.7.35：修好导出卡在「编码器长时间没有输出画面」。勾 CPU 也会卡住，不是显卡问题。

- 剪过多段的时间线不再用多层 `overlay` 互等后面的 `trim`。顺剪改为和音频一样的 `concat` 顺序拼接，4K HEVC 多段切除后也能出第一帧。
- 必须叠层时（重叠、单独缩放/裁切）每段先补到 t=0，避免再死锁。
- 逐词字幕 PNG 先收成一条 concat 叠层，不再几百张整帧一起塞进滤镜图。
- 达芬奇占着 Intel 核显时自动改走 CPU；GPU 卡住会强杀再回退。CPU 等第一帧的时间加长，失败不再误怪显卡。
