# 快剪 QuickCut 2.4.2 修复清单

基线：用户于 2026-08-08 上传的 `Contents(1).zip`，经核对为 QuickCut 2.3.0 完整源码与 Apple Silicon 应用内容。本目录只从该基线继续修改。

## P0：必须先修复

- [x] 首页删除工程使用软件内确认框，点击后真正调用可恢复删除并立即刷新首页。
- [x] “重置工程”使用软件内确认框，真正重置磁盘工程和当前界面，不能只清空表面状态。
- [x] 删除主视频、叠加视频或关联音频后清除失效选择，不允许属性面板继续引用已删除对象。
- [x] 删除最后一个主视频后清空播放器、波形、字幕和预览；拖入下一段视频时可重新成为主视频。
- [x] 视频先立即进入播放器和轨道，真实波形、音频预览及首帧在后台生成；不需要先运行“自动剪停顿”，也不会用同步 FFmpeg 阻塞界面。
- [x] 工程素材采用异步硬链接/APFS 克隆优先策略，避免主线程同步复制大视频；媒体探测、缩略图和波形分析均改为异步任务，并限制并发数。
- [x] Finder 拖入素材区、预览区、时间线时保留准确落点；预览区拖入必须立即出现在画布和时间线。
- [x] 文件面板和素材库显示真实视频首帧、图片缩略图、音频波形预览；加载失败时显示明确的类型占位图。
- [x] 应用关闭时先触发自动保存，再关闭本地媒体服务和窗口进程，不能卡住需要强制结束。
- [x] 应用包必须使用 2.3 基线内的蓝底白色剪刀图标，禁止混入旧图标缓存文件。

## P1：工程、时间线与轨道

- [x] 首页工程卡片保存并显示工程首个视频的缩略图；备份恢复后会重建缓存。
- [x] 时间线始终保留时间尺；删除素材或变速只改变素材时长，不把时间尺压缩为 0。
- [x] 首个同类素材进入默认轨道，第二个及以后才自动建立同类型新轨道。
- [x] 视频自带音频时自动建立对应音频片段；链接开启时共同移动/删除，关闭时可独立处理。
- [x] 视频、音频、图片、文字、字幕片段可跨同类轨道上下拖动；放到空白区域时自动建立同类轨道。
- [x] 轨道名称区和时间线内容区同步垂直滚动，轨道不可与对应内容错位。
- [x] 框选、Shift/Command 多选、批量删除、撤销/重做、吸附、切割及两端修剪均绑定真实处理器。
- [x] 视频/音频两端修剪不能超出源素材；图片、文字可自由延长。
- [x] 静帧截取时先弹出保存路径，保存后再加入图片轨道。
- [x] 各面板分隔线可调整大小，菜单名称保持横排，并保存布局。
- [x] 左侧面板最小宽度保证“文件、素材、字幕、样式、字体”始终单行，不允许压成竖排或两行。
- [x] 时间尺按住鼠标可连续左右拖动播放头，快速拖动通过逐帧节流保持流畅。

## P1：字幕、画面和音频

- [x] 字幕样式面板保持深色背景，预览文字使用清晰的高对比色；悬停时播放该样式动画。
- [x] 正确文案差异轨每一条都有独立“替换”按钮，只替换用户主动选择的口播字幕词句，并保留其他差异供继续判断。
- [x] 字幕、文字、图片、视频在预览窗口选中后显示边界框，可拖动、缩放并与导出位置一致。
- [x] 音量变化即时反映在真实波形高度和片段音量线上；整轨与单片段参数分离。
- [x] 音频降噪参数变化可试听，应用整轨后时间线监听与导出均使用同一设置。
- [x] 调色各项保持独立含义；美颜采用保边平滑、瑕疵弱化与细节恢复，避免仅增加模糊。
- [x] 速度变化同步缩短视频、音频、字幕和其他关联轨道。
