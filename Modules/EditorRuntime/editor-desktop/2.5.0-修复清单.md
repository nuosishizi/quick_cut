# 快剪 QuickCut 2.5.0

- 导出时长改为所有可见成片素材的最晚结束时间；时间线显示范围、正确文案差异轨和问题标记不再延长导出。
- 打开旧工程时自动修正被诊断轨错误撑长的时间线。
- 时间线改为保留式渲染：滚动只移动视口并重绘已缓存波形，不再清空、重建素材块。
- 所有横向滑块增加 `−` / `+` 微调按钮；时间线缩放每次调整 5，视频缩放每次调整 1%。
- 字体选择移入右侧文字/字幕属性；增加载入字体、开源字体、字间距和行间距。
- 字幕导出支持字间距，标题导出支持行间距。
- 导出新增素材帧率、自动推荐码率和 Rec. 709 SDR 默认设置。
- macOS 优先使用 VideoToolbox 硬件编码；不可用时自动回退到高质量软件编码。
- 导出窗口持续显示百分比进度条。
- 安装程序在安装前校验 Bun、FFmpeg、FFprobe、WebView 和语音识别组件，避免缺少运行组件。
