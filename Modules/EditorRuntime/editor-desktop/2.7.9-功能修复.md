# 快剪 QuickCut 2.7.9

达芬奇字幕底不再变成「一词一块黄泡」，字也不再发虚。

## 根因

Fusion Text+ 官方 Appearance：`0=字填充`，`1=Border Fill`（底）。Level：`0=整句`，`1=行`，`2=词`，`3=字`。

之前 Type 用成字填充、Level 用成 2/3，底变成逐词黄块。AutoSubs 母版 Follower 默认 Softness=1，卡拉 OK 又被误开成 Fade（Duration 0 + Mode Both），整段字被淡出，看起来半透明。

AutoSubs 自己的底好，是因为它只用 Element 4 的 Border Fill，并和自己的透明度系统绑在一起。整句金底必须用 Element 5 的 **Type 1 + Level 0**，并关掉 Fade、Softness。

## 修复

- 整句底：Type 1（Border Fill）+ Level 0（Text）
- 卡拉 OK 不再开 Fade
- 写样式前断开 Opacity stretcher，Softness 归 0
